# Buildings

Building footprints and their constituent parts, conflated from OpenStreetMap, Esri Community Maps, Google Open Buildings, Microsoft ML Building Footprints, and other sources. Two collections: [Buildings](building/collection.json) holds the footprints, and [Building Parts](building_part/collection.json) holds sub-features that refine a footprint's shape or height.

Read the [Overture buildings schema reference](https://docs.overturemaps.org/schema/reference/buildings/building/) for the authoritative field definitions.
